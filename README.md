# 模拟聊天工作台 V2.0

本地 Python + Streamlit 工具，用来制作虚构商务聊天，供培训与演示使用。界面借鉴常见移动聊天布局。导出图片不显示模拟标识，因此使用者需明确说明其为模拟内容。它不是 WhatsApp 客户端，也不连接或导入真实聊天。

## 安装与启动（Windows PowerShell）

```powershell
cd D:\WhatsAPP
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

打开 Streamlit 显示的本地地址。没有 API 密钥时，手动创建、离线示例、消息编辑、图片、预览、JSON 保存和 PNG/ZIP 导出均可使用。离线示例只覆盖内置语言（法语、英语、西班牙语、德语、中文）；未覆盖语言会使用英语示例并可手动改写。

PNG 导出需要浏览器。程序优先使用 Playwright 自带 Chromium，也可使用本机 Chrome；若两者均没有，运行 `.\.venv\Scripts\python.exe -m playwright install chromium`。

## 可选 AI 配置

仅在你决定启用 AI 时，把 `OPENAI_API_KEY` 放入当前进程环境变量或项目根目录的 `.env.local`；不要写入聊天 JSON。`.env.local` 已列入 `.gitignore`，程序只在调用 AI 时读取它，现有进程环境变量优先。可通过 `OPENAI_MODEL` 选择支持结构化输出的模型，默认 `gpt-4o-mini`。模型生成后内容进入可编辑列表；事实、报价和产品规格仍需人工确认。单条重写只改目标文本，并保留该条 ID、图片、时间及其他消息。没有密钥或 API 项目额度时 AI 按钮给出明确错误。

## 使用

1. 在“单组聊天与编辑”设置人物、产品、关键词、时间规则和对话界面样式（WhatsApp 手机风格、微信风格或宽屏聊天风格）。打开“三人及以上群聊”后填写群名，可增加成员、设置姓名和头像；消息编辑器可为每条消息选择发送者。群聊至少包含买方、卖方和一名其他成员。离线示例会轮流安排群成员发言；AI 群聊要求模型在消息数量足够时覆盖所有成员。宽屏聊天风格可选择柔和暖色或清爽中性色调。新建对话默认法国/法语、手机充电器、10 条、09:00–16:30、5–30 分钟，并统一使用北京时间 `Asia/Shanghai`；可从下拉菜单选择巴黎、伦敦等时区，或输入自定义 IANA 时区。国家与时区独立，已有聊天记录不会被批量改写。更换已有聊天的时区会换算显示钟点，不会静默改变已保存消息的时间点；如要按新时区的 09:00–16:30 重新排布，请明确使用时间重算功能。国家、语言、时区仍用于编辑与排时，但不显示在聊天画面或导出的截图中。界面样式保存在聊天 JSON 中，预览、PNG 和批量导出共用该选择。
2. 选择“完全手动”或“离线示例”创建消息。“聊天头像”区域可分别上传、更换或移除买卖双方的头像，选定图片后立即应用；买方头像显示在 WhatsApp 风格顶部，微信风格在消息旁显示对应发送方头像。“聊天顶部状态（模拟）”可选择隐藏、在线或手动设置最后上线时间；设置下方会立即显示顶部预览，完整聊天顶部和导出 PNG 也会同步显示，并保存到聊天 JSON；不连接真实 WhatsApp。上传产品图片后可在指定消息里选择附件。所有图片按资源 ID 保存在 `data/assets`；移除头像只解除当前聊天的引用，不删除本地图片文件。
3. 编辑文本、发送方和精确日期分钟。人工时间被固定；自动重算会保留它。调整顺序保留原时间并显示冲突提醒。要覆盖人工时间需点明确的全量重算按钮。可按纯文本、图片、图片加文字分别覆盖回复间隔；跨日对话用“结束日期偏移”指定 1–7 天。离线示例会把“必须出现的关键词”写入买方的待确认提问，不把价格或交期当成卖方已确认承诺；修改关键词后需明确重新生成，已有消息不会自动改写。
4. 保存聊天或另存新版本；下载 JSON；准备并下载高清 PNG。完整 HTML 由同一模板用于预览和 Playwright 导出。
5. 批量页默认各组使用北京时间，仍可单独编辑每组国家、语言、IANA 时区、人物和数量。失败组保留错误与重试入口，成功组可独立编辑、保存、导出，也可打包 ZIP。
6. 历史和模板页可载入记录。删除需先点“删除”，再点“确认删除”。

### PI（形式发票）模拟讨论

在单组编辑页上传含可复制文字的 PDF（最多 10 MB、10 页），点击“提取 PI 文字”。程序只在本机提取文字并尝试识别编号、买卖方、产品、数量、金额、付款和交期等字段。请对照原文逐项修改，再点击“确认以上 PI 字段用于模拟讨论”。选择“PI 商务讨论”可生成可编辑的离线对话；现有“AI 生成”不会收到 PI 字段。原始 PDF 和提取全文不写入聊天 JSON，已确认字段会随聊天保存，因此保存前请检查是否包含不应保留的真实客户或价格信息。

字段识别依赖单据文本布局，可能漏识别或误识别；扫描 PDF 和图片暂不支持。PI 离线讨论提供中文和英语模板，其他聊天语言回退英语。对话仅为模拟核对，不能代替正式报价或合同确认。

### 可编辑 PI 形式发票与内容转换

“PI 形式发票”工作区可编辑编号、日期、买卖双方资料、商品明细、数量/单价、币种、贸易/运输/付款条款、费用、收款资料、附加条款与备注。商品和附加条款可添加、修改或删除；金额按明细自动计算。草稿可保存、另存版本、导入/导出 JSON，也可导出标有“模拟草稿”的 PNG 或 PDF。PDF 导出前要求编号、日期、买卖方、币种及有效商品明细；其余建议要素若缺失，会在界面提示人工补齐。

可以从可复制文字的 PI PDF、当前微信/WhatsApp 风格聊天或当前邮件记录建立 PI 候选草稿；也可以从当前 PI 生成新的可编辑聊天（可选 WhatsApp 或微信风格）和邮件草稿，再在各自编辑器增删修改。转换是显式操作，不会自动同步或覆盖已保存记录。反向转换只识别带字段标签的文字（例如“PI 编号：…”“数量 1：…”），自由叙述不会被当作已核实发票要素；导入候选项、金额及条款都须核对。程序不连接微信、WhatsApp、Gmail，也不发送邮件。仅在本地处理上传 PDF；源 PDF 原文不写入 PI JSON。

### Gmail 风格模拟邮件记录

在“邮件记录截图”工作区编辑主题、显示账号、发件人、收件人、抄送、发送时间和正文。可添加多封往来邮件，按 Gmail 风格实时预览后保存到本地，或下载 JSON 和高清 PNG。预览与 PNG 中不显示 DEMO 提示或演示页脚。该功能只生成本地演示截图，不连接 Gmail，也不发送邮件。保存前请检查内容是否含有不应保留的真实客户信息。

`data/chats`、`data/templates`、`data/assets`、`data/emails` 与 `data/invoices` 是本地持久数据，重启应用后保留。迁移时请连同整个 `data` 目录复制；单独聊天 JSON 不含图片二进制。不要用真实客户头像或未经授权素材。

## 测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

测试覆盖默认值、时间固定与冲突、关键词、图片与 JSON 保存、批量失败隔离、完整 PNG 和 ZIP。AI 实际调用需要用户启用并提供密钥，未提供时不能声称已通过线上调用验收。

## 结构

| 路径 | 用途 |
|---|---|
| `app.py` | Streamlit 页面与交互状态 |
| `chatbench/models.py` | 数据结构与验证 |
| `chatbench/time_engine.py` | 自动、人工、混合时间规则 |
| `chatbench/generator.py` | 离线示例与可选 AI 接口 |
| `chatbench/renderer.py` | HTML/CSS 聊天模板 |
| `chatbench/mail.py` | 模拟邮件记录、校验与 HTML 预览 |
| `chatbench/invoice.py` | PI 结构、金额校验与双向内容转换 |
| `chatbench/invoice_render.py` | PI HTML 预览和 PDF 导出 |
| `chatbench/invoice_ui.py` | PI 编辑、导入、保存与转换界面 |
| `chatbench/exporter.py` | Playwright PNG 与 ZIP |
| `chatbench/storage.py` | JSON、图片和模板存储 |
| `tests/` | 核心回归测试 |

## 已知边界

- WhatsApp 手机风格默认使用 420 CSS 像素宽度；微信风格至少使用 720 CSS 像素宽度，并在窄预览窗口自适应。微信风格不显示纯空白消息；首条可见消息、跨日及相邻可见消息间隔达到设定值时显示居中时间，默认间隔 5 分钟，可调整为 1–60 分钟。消息编辑器可勾选“在此消息前显示时间”。当天以对话日期为准显示钟点，其他日期显示昨天或具体日期；设置只控制显示，不重排消息时间。微信群聊在标题显示成员数量，左侧昵称显示在气泡上方，右侧自己的消息不显示昵称。宽屏聊天风格使用 1000 CSS 像素宽度，并在编辑页提供完整宽屏预览。WhatsApp 风格背景采用暖白底色、密集低对比度线稿的原创 SVG 纹样，参考用户截图的视觉密度，但并非官方壁纸原图；截图里的第三方插件按钮不会加入工作台。字体优先使用系统字体，跨平台字形可能略有差异。默认导出 3 倍像素密度。
- 夏令时不存在的本地时间会报错；夏令时重复的小时当前使用该时区的默认第一次出现。若需精确区分两次出现，应增加 `fold` 选择。
- 批量离线示例属于固定演示文案，并非 AI 多语言生成；对未知语言回退英语。
- 预览与 PNG 共享 HTML/CSS，但不同浏览器环境的字体文件可产生细微字形差异。
